# Application and editor adapters

main.cpp resolves Git and the recovery directory, then builds an Application, the composition root that owns every collaborator and hands Main.qml the objects it uses. SessionModel lists the SessionStore's files for the window, and FilePresentation and SessionHandoff turn their facts into the states (FileStates) and sentences views show. Selection names the selected file; SelectedFile projects its comparison. FileCommands, ChoicePreviewFlow and FileNavigator run the commands, previews and navigation the views trigger, and CommandFeedback shows their outcome. SessionLoader opens the repository, SessionCompletion finishes or leaves the session and MergetoolStatus shows waiting launchers. ResultEditorAdapter translates native text edits and shared actions into durable result revisions. EngineText and ProblemText turn the engine's and the adapters' typed results into translated sentences; nothing below this directory writes one.

Add Qt-facing models, view-facing command objects and editor/domain translations here. Put visual components in ui/, Git protocols in git/, file histories and background session operations in session/.
