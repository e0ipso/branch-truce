# Comparison window and native controls

Main.qml assembles the sidebar, toolbars, file notices and comparison workspace. The pane, gutter, choice, menu and dialog components present controller state. TextBlocks, PaneMarks and ConnectorBands compute presentation geometry; ComparisonPanes and PassageSearch support aligned reading. ContextMenuHost routes context-menu gestures from the source and result editors.

Add QML components and C++ helpers that exist to render or operate those components here. Keep session state and writes in the controller and its collaborators. Syntax formatting belongs in highlighting/, and native result edit translation belongs in app/.
